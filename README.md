# Портфолио Мари Климовицкой

Статическое портфолио в эстетике Y2K-журнала. Сайт не использует внешние зависимости и собирается в папку `dist`.

## Локальный запуск

```bash
npm run build
npm run preview
```

Откройте `http://localhost:4173`.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт при push в ветку `main`. В настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**.
